==================================================
            ИНСТРУКЦИЯ ПО РАБОТЕ С STEGO
==================================================

1. ОПИСАНИЕ ПРИЛОЖЕНИЯ

Stego — приложение для скрытия и извлечения текста
внутри изображений.

Текст сохраняется в EXIF-метаданных изображения
(UserComment), поэтому визуально изображение
не изменяется.

Приложение поддерживает:
- консольный режим (CLI);
- графический интерфейс (GUI).


==================================================
2. СИСТЕМНЫЕ ТРЕБОВАНИЯ
==================================================

Для работы приложения необходимо:

- Windows (для GUI-версии);
- установленный .NET 8 Runtime или SDK.


==================================================
3. ПОДДЕРЖИВАЕМЫЕ ФОРМАТЫ
==================================================

Поддерживаются изображения:
- JPG / JPEG
- PNG
- BMP
- TIFF

Максимальный размер сообщения:
примерно 65 000 байт в UTF-8.

Важно:
Количество символов зависит от языка.
Русский текст занимает больше памяти,
чем английский.


==================================================
4. РАБОТА ЧЕРЕЗ КОНСОЛЬ (CLI)
==================================================

------------------------------
4.1 Скрытие сообщения
------------------------------

Команда:

stego encode -i image.png -o secret.png -m "Привет"

Параметры:
-i   путь к исходному изображению
-o   путь сохранения результата
-m   сообщение для скрытия

После выполнения команды будет создано
новое изображение со скрытым текстом.


------------------------------
4.2 Извлечение сообщения
------------------------------

Команда:

stego decode -i secret.png

Параметры:
-i   путь к изображению

Если скрытое сообщение найдено,
оно будет выведено в консоль.


------------------------------
4.3 Полезные советы
------------------------------

- Если сообщение содержит пробелы,
  используйте кавычки.

- Для более надежного хранения
  рекомендуется использовать PNG или TIFF.

- Некоторые мессенджеры и соцсети
  автоматически удаляют EXIF-данные.
  После отправки изображения скрытый
  текст может быть потерян.


==================================================
5. ВОЗМОЖНЫЕ ОШИБКИ
==================================================

[Unsupported format]

Выбран неподдерживаемый формат изображения.

Используйте:
JPG, JPEG, PNG, BMP или TIFF.


[Message too large]

Сообщение слишком большое.

Попробуйте сократить текст.


[No EXIF data / EXIF is empty]

В изображении отсутствуют скрытые данные.

Возможные причины:
- файл не был закодирован через Stego;
- метаданные были удалены после обработки.


==================================================
6. РАБОТА ЧЕРЕЗ ГРАФИЧЕСКИЙ ИНТЕРФЕЙС (GUI)
==================================================

------------------------------
6.1 Запуск приложения
------------------------------

Запустите приложение без аргументов,
после чего откроется графическое окно.


------------------------------
6.2 Вкладка «Кодирование»
------------------------------

1. Выберите изображение или
   перетащите его в окно.

2. Введите текст для скрытия.

3. Проверьте путь сохранения.

4. Нажмите кнопку кодирования.

После завершения приложение:
- покажет уведомление;
- сохранит новое изображение
  с суффиксом "_encoded".


------------------------------
6.3 Вкладка «Извлечение»
------------------------------

1. Выберите изображение.

2. Приложение автоматически
   извлечет скрытый текст.

3. Результат появится
   в текстовом поле.

Если данные отсутствуют,
появится сообщение:

"Нет данных"


------------------------------
6.4 Сохранение текста
------------------------------

1. Укажите путь сохранения.

2. Нажмите кнопку сохранения.

3. Текст будет сохранен в UTF-8.
